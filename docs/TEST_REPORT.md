## 十萬次亂數模擬

`npm run test:statistics` 執行 100,000 次獨立完整洗牌，每次以真實 Web Crypto 擲骰、拒絕超界並抽三張。每次檢查牌陣內不重複；記錄每個固定位置的 78 類頻率、首張抽取卡牌、7,800,000 張的方向、相鄰次首張相同次數。原始數字見 statistics.json；每次重跑會自然變動。

| 指標 | 本次觀測 | 預先設定檢查 |
| --- | --- | --- |
| 首張各牌頻率 | 1203–1365 次；期望 1282.051 次 | χ²(77) = 58.834 < 140 |
| 逆位比例 | 3,898,103 / 7,800,000 = 49.975679% | 50% ± 0.107417 個百分點（6 SE） |
| 固定位置分布 | 78 個位置的最大 χ²(77) = 105.390 | 每個位置 < 170 |
| 相鄰模擬同一首張 | 1308；期望 1282.038 | 與期望差小於 213.452（6 SE） |
| 第一輪 D100 | χ²(99) = 117.307 | 原始分布留存作補充觀察 |
| 第一輪超界重擲 | 28,247 次 | 全部拒絕，不映射成有效位置 |

單一首張卡牌機率期望為 1/78 ≈ 1.28205%；100,000 次的邊際標準誤約 0.03558 個百分點，近似 95% 範圍為 ±0.06973 個百分點（非 78 類同時信賴區間）。方向估計 SE 為 0.017903 個百分點；表中採 6 SE 的寬鬆回歸警戒線，避免對真正隨機樣本設定過窄門檻。

卡方以 Σ(觀測−期望)²/期望 計算。140 與 170 為保守的自動回歸門檻，固定位置使用較寬門檻處理 78 次比較；不是精確 p 值或公平性證明。統計通過表示本次未偵測到列出的偏差，不能證明所有可能模式皆不存在。公平性主要由 Web Crypto、整數拒絕採樣、Fisher–Yates 和無問題內容輸入的抽牌函式支撐。

## 限制與設計取捨

使用原創象徵 SVG，不冒稱傳統完整 RWS 敘事畫面。採 CSS 多面骰呈現而非 Three.js。截圖中的卡牌與骰點由實際亂數產生，因此每次不同。已測行動模擬，尚無實體 iOS／Android、Safari、Firefox 的驗證；未進行正式無障礙或專業塔羅內容審核。尚未驗證使用者實際 Vercel／Cloudflare 帳號部署；提供可直接部署的 dist 與步驟。已知記錄清除與未儲存流程刷新限制見 README。
